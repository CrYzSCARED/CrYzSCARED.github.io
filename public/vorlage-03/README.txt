VORLAGE 03 – AFTER HOURS | FERTIGE FASHION-WEBSITE

Die ZIP enthält ALLE 9 ORIGINAL-VIDEOS in optimierter Form.
Du musst keine Videos oder Bilder mehr hinzufügen.

GitHub Pages mit deinem bestehenden Vite/React-Projekt:
1. Öffne dein Repository auf GitHub.
2. Öffne den Ordner public.
3. Ersetze den gesamten Ordner vorlage-03 durch den Ordner vorlage-03 aus dieser ZIP.
   Achte darauf, dass sich unter public/vorlage-03/index.html die Startseite befindet.
4. Lade die Unterordner assets/images und assets/videos vollständig mit hoch.
5. Commit changes ausführen, GitHub Actions abwarten.
6. Öffne https://innovaone.ch/vorlage-03/ (bei Bedarf Strg + F5).

Enthalten:
- index.html – Website
- assets/style.css und assets/site.js – Design und Funktionen
- assets/videos/44545.mp4 usw. – neun echte Mixkit-Clips, für kleinere Videorahmen optimiert
- assets/images/clip-44545.webp usw. – echte Filmstandbilder aus denselben Clips
