VORLAGE 03 — Automotive Designkonzept
=========================================

Diese Website ist eine eigenständige, fiktive Automotive-Designstudie.
Sie stellt kein echtes Unternehmen und keine buchbaren Leistungen dar.

DIE AUTO-DREHUNG
- Maus: Auf dem Auto nach links/rechts ziehen.
- Smartphone: Mit dem Finger seitlich wischen.
- Tastatur: 3D-Ansicht fokussieren und Pfeiltasten verwenden.
- Bedienung: Pfeile, Auto-Rotation, Reset und Lackfarben.
- Beim normalen Scrollen wird die Ansicht leicht gedreht, solange
  der Benutzer noch nicht selbst mit dem Auto interagiert hat.

TECHNIK
- Reines HTML/CSS/JavaScript + lokales WebGL.
- KEINE externen JavaScript- oder 3D-Modell-Dateien.
- Die 3D-Geometrie wurde speziell für diesen Demo-Entwurf gestaltet.
- Google Fonts werden extern geladen; es gibt Systemfont-Fallbacks.
- Alle Fotos/WebP-Dateien liegen lokal im Ordner assets/.
- Die Bildmotive sind KI-generierte, konzeptionelle Visualisierungen.
- WebGL-Fallback: Statisches Sportwagenbild, wenn WebGL nicht unterstützt wird.

GITHUB PAGES / VITE
1. ZIP entpacken.
2. Den vollständigen Ordner 'vorlage-03' mit Unterordner
   'assets' in dein Repository unter public/ hochladen.
3. Auf GitHub 'Commit changes' anklicken.
4. Nach Deployment die URL aufrufen:
   https://innovaone.ch/vorlage-03/

Keine Dateien direkt in public/ ablegen, sondern unter
public/vorlage-03/ belassen.

DATEIEN
index.html      Hauptseite
assets/styles.css    Layout und mobile Anpassungen
assets/app.js        Interaktionssteuerung, Menü, Animationen
assets/car3d.js      Eigenständige 3D-Engine und Fahrzeuggeometrie
assets/*.webp        Lokale Bilddateien

HINWEIS
Diese Website ist eine fiktive Gestaltungsvorlage und nicht als realer
Garagenauftritt oder echtes Fahrzeug-Angebot zu verwenden.
