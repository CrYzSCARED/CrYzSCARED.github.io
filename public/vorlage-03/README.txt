VORLAGE 03 – AFTER HOURS / FASHION CAMPAIGN
==========================================

Fertiges GitHub-Pages-Paket (mit neun lokalen Videos).

UPLOAD:
1. ZIP entpacken.
2. Den kompletten Ordner 'vorlage-03' nach 'public/' in deinem GitHub-Projekt kopieren.
3. Bestehende Dateien im Ordner 'public/vorlage-03/' ersetzen, auch assets/style.css und assets/site.js.
4. GitHub Actions / Deployment abwarten.
5. Danach https://innovaone.ch/vorlage-03/ öffnen und ggf. mit Strg+F5 neu laden.

ÄNDERUNGEN DIESER VERSION:
- Scroll-Fortschrittsstreifen entfernt.
- Pinker Hinweisbalken dauerhaft oben fixiert; Navigation bleibt darunter sichtbar.
- Responsive Handylayouts verbessert.
- Sonderzeichen, Pfeile und Stern durch SVG-Icons ersetzt.
- Alle neun lokal gehosteten Originalvideos sind weiterhin enthalten.

HINWEIS:
Fiktives Fashion-Designkonzept, keine offizielle Markenwebsite.
Stockfilme von Mixkit. Nutzungsbedingungen der konkreten Clips beachten.
